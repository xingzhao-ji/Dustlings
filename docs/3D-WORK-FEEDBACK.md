Idle and travel use their original body-relative hand transforms. There are still seven geometry groups and the same shared meshes/materials.

The original `pose(delta, elapsed, speed, working, birth_age, celebrating, gentle_motion)` interface remains. `working` is an activity strength from 0 to 1; root now supplies 1 only when that helper actually removed dust. It is not the raw per-tick removed amount. The animation blends down while travelling and suppresses cleaning during the fountain celebration. Gentle motion uses a steady working lean/contact silhouette with no repeated sweep; the existing reduced breathing, blink and leaf response remain.

Two allocation-free getters let the caller align local dust response with the pose:

- `work_stroke() -> float`: 0–1 contact strength during the grounded sweep. It becomes zero immediately when incoming work is zero, during celebration, or at normal travel speed, even while a visual recovery is still blending. Gentle motion provides a low steady 0.30 when working.
- `work_contact() -> Vector3`: the world-space midpoint of the two hands' analytic lowest points. Root can read the preceding rendered pose during a physics tick and gate emission on actual positive dust removal. The getter never emits effects or authorizes production.

Root owns the complementary activity signal, facing direction toward the actual patch when stopped, and bounded local dust wisps. Those changes need integrated verification together; this document does not claim the animation alone solves the critic's finding. No new per-helper sound is added.
